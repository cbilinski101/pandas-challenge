## 📌 Project Overview

The **PyCitySchools Analysis** examines school performance based on various factors, such as school type, spending per student, and school size. The dataset includes student and school information to analyze overall academic success and trends.

## 📊 Key Findings

- **Charter Schools** have an **Overall Passing Rate** of **90%**, while **District Schools** have only **53%**.
- **Smaller and Medium-Sized Schools** tend to perform better (89%-90% passing) than **larger schools** (58% passing).
- Schools that **spend less per student** actually have **higher passing rates**, challenging the assumption that higher spending leads to better outcomes.

## 📁 Dataset

The analysis is based on the following datasets:

- [`schools_complete.csv`](schools_complete.csv) - Contains school-level data such as type, budget, and size.
- [`students_complete.csv`](students_complete.csv) - Contains student performance data including scores and demographics.
